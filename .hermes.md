# Working in this repo

Read `INDEX.md` first. It is the only doc guaranteed current; `README.md` is for other
humans, `docs/` is reference.

## Hard rules

- **The camera path is dead.** No phone page, no AprilTag, no QR pairing. Tags are NFC
  stickers on the globes, read by the Arduino.
- **Never use `PICC_IsNewCardPresent()`** for presence. Use `escTagPresent()` (WUPA);
  a resting tag is HALTed and REQA will never see it again.
- **RC522 runs on 3.3 V.** Never 5 V, not even "to test".
- **Do not touch `songs/` filenames** — `index.html` names them literally.
- **Slug format** `[a-z0-9-]{1,24}`; anything else must be rejected by both writer and
  reader (`ndefValidSlug`).
- Firmware timing/pins live in `firmware/ESC_NFC_Pedestal/config.h`; shared pins in
  `firmware/libraries/ESCShared/src/pins.h`.

## Before claiming work is done

Run `./run_tests.sh`. It must print ALL PASS twice, 16 node tests passing, and
`Sketch uses` for both sketches. Anything about hardware behaviour that was not actually
run on a board must be described as unverified — say so plainly.

## Style

Match the existing comments: say *why*, in one short sentence, in the second person
("a tag resting here is HALTed between reads"). No changelog narration in code.
